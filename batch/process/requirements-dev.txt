# Dev/test-only dependencies for running this component's unit tests
# locally. Self-contained on purpose, matching this repo's per-component
# toolchain pattern (see lambda/ingest/package.json): NOT installed into the
# Batch job's container image (that's requirements.txt only) and NOT pinned
# to the exact versions in requirements.txt.
#
# Why not just `-r requirements.txt`: requirements.txt pins boto3/botocore/
# urllib3 exactly for the job's python:3.13-slim container image. This
# venv runs against whatever Python is on the developer's machine (verified
# against 3.9 here), and botocore's own constraints forbid urllib3==2.x
# before Python 3.10 — so those exact production pins are not installable
# here. Testing only needs *a* working boto3, not the container's exact
# one: process.py's boto3 calls are fully mocked in tests, never made for
# real.
pytest>=8.0,<9
pytest-cov>=5.0,<6
boto3>=1.34,<2
